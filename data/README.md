# Данные варианта 1

**Источник:** синтетические данные, сгенерированы скриптом `../generate_data.py`.

**Seed:** `10131 = 10000 + 100·Q + N`, где `Q = 1` (группа 517), `N = 31`.

**Файлы:**

- `products.csv` — 5 продуктов: прибыль на единицу, максимальный спрос,
  трудоёмкости на четырёх станках;
- `machines.csv` — 4 станка: доступный фонд времени;
- `params.json` — единицы измерения и seed.

**Процедура генерации.** За основу взяты экспертные значения прибыли
`[120, 90, 150, 70, 110]` тыс. руб./ед., спроса `[40, 60, 30, 80, 50]` ед. и
матрицы трудоёмкостей. К прибыли добавлен мультипликативный шум
`N(1, 0.03)`, к трудоёмкостям — `N(1, 0.05)`; значения округлены до 0.01.
Фонды времени станков фиксированы: `[260, 240, 300, 280]` ч.

**Единицы:** `x_j` — единицы продукции; `c_j` — тыс. руб./ед.;
`a_mj` — часы на единицу; `b_m` — часы; `d_j` — единицы.

**Перегенерация:**

```bash
python generate_data.py
```
